# تطبيقات الخادم (Backend Apps)

كل مجلد تحت `apps/` هو تطبيق Django مستقل ضمن مشروع `config`. النمط العام لكل تطبيق:

```
apps/<name>/
├── apps.py        # إعداد التطبيق واسمه
├── models.py      # نماذج قاعدة البيانات
├── serializers.py # تحويل النماذج إلى JSON
├── views.py       # نقاط النهاية
├── urls.py        # مسارات `/api/v1/<app>/...`
├── admin.py       # تسجيل النماذج في Django Admin
└── migrations/    # ترحيلات قاعدة البيانات
```

| التطبيق | الغرض | مسارات رئيسية (ضمن `/api/v1/`) |
| --- | --- | --- |
| `academics` | المراحل والمواد والمناهج والوحدات | `/academics/...` |
| `ai` | نماذج الذكاء الاصطناعي والتوليد والبرومبتات | `/ai/...` |
| `blog` | المقالات | `/blog/...` |
| `core` | النواة: اللغات والترجمات والإحصاءات | `/core/...` |
| `courses` | الدورات | `/courses/...` |
| `ebooks` | الكتب الإلكترونية | `/ebooks/...` |
| `gamification` | النقاط والشارات والتحديات | `/gamification/...` |
| `lessonplans` | خطط الدروس (توليد/تصدير/سوق) — يستهلك حصة `ai_lesson_plans` | `/lesson-plans/...` |
| `marketplace` | خدمات السوق والطلبات والمراجعات والمدفوعات | `/marketplace/...` |
| `pages` | الصفحات الثابتة والقوائم والقوالب والثيمات | `/pages/...` |
| `subscriptions` | الباقات والاشتراكات والخدمات وحِصص الاستخدام | `/subscriptions/...` |
| `themes` | التصميمات (المظهر) | `/themes/...` |
| `users` | المستخدمون والمصادقة والملف الشخصي | `/auth/...` |

## ملاحظات

- **الترجمة**: الحقول المتعددة اللغات (أسماء، أوصاف) تُخزَّن JSON بصيغة `{"ar": "...", "en": "..."}`، وتُعرَض حسب `?locale=` أو `Accept-Language`.
- **الصلاحيات**: نقاط نهاية الإدارة تحت `admin/` محمية بـ `IsAdminUser` (حساب staff).
- **الدفع**: `apps/marketplace/payments.py` يوفّر واجهة موفّر موحّدة (Stripe/MyFatoorah) تستخدمها تطبيقات الاشتراكات والسوق.
