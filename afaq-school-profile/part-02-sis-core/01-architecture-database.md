# الجزء الثاني: البنية التنظيمية ونماذج البيانات (SIS Core & Database)

لضمان التوافق مع الأنظمة المدرسية المعتمدة (مثل نظام **EduWave**)، تعتمد المنصة على هيكل هرمي مترابط:

```
المديرية (Directorate)
   └─ المدرسة (School)
        └─ العام الدراسي (Academic Year)
             ├─ الصف (Grade)
             │    └─ الشعبة (Section)
             │         ├─ الطالب (Student) ← مرتبط بعام دراسي
             │         └─ إسناد المعلم (TeacherAssignment: معلم + مادة + شعبة + عام)
             └─ ولي الأمر (Parent) ← مرتبط بطلبه عبر FamilyLink
```

## 1. الكيانات الرئيسية (Models)

### أ. المدارس والسنوات الدراسية (Schools & Academic Years)
* **School:** اسم المدرسة، المديرية التابعة لها، والرمز التعريفي (`School Code`).
* **AcademicYear:** العام الدراسي (مثل 2025/2026) مع أعلام (البداية/النهاية، `is_current`) لإدارة الأرشيف والترحيل السنوي.

### ب. الصفوف والشعب الصفية (Grades & Sections)
* **Grade:** الصف الدراسي (مثل: الصف السادس الأساسي، الأول الثانوي).
* **Section:** الشعبة الصفية (مثل: الشعبة أ، الشعبة 1). يربط الطالب بالمدرسة والصف والشعبة للعام الدراسي الحالي.

### ج. إسناد المعلمين (Teacher Assignments)
* **TeacherAssignment:** ربط المعلم بالمادة الدراسية والشعبة والصف ضمن **عام دراسي محدد**. يضمن ظهور طلاب الشعبة فقط لمعلم المادة، ويسمح بإعادة توزيع المعلمين كل عام دون التأثير على السنوات السابقة.

### د. المستخدمون والأدوار وأسماء المستخدمين الفريدة (Users, Roles & Unique Usernames)
* **SchoolAdmin:** مدير المدرسة — يدير مدرسته، معلميه، شعبه، طلابه، وأولياء الأمور.
* **Teacher:** المعلم — يدير شعبه ومواده وواجباته وتنبيهاته.
* **Parent:** ولي الأمر — يتابع أبناءه وتقاريرهم.
* **Student:** الطالب — يرى واجباته ودروسه وتنبيهات شعبه.
* **أسماء المستخدمين الفريدة (Unique Usernames):** يُنشأ لكل مستخدم اسم مستخدم فريد وكلمة مرور تلقائياً أو يدوياً، وفق القاعدة:
  * الطالب: يستخدم الرقم الوطني إن توفر، أو نمط `student.{email}`.
  * المعلم/مدير المدرسة: البريد الإلكتروني الرسمي أو `teacher.{email}`.
  * ولي الأمر: `parent.{email}` مع ربطه بأبنائه.
  * تُفرض فريدة الاسم عالمياً (`unique=True`) لمنع تكرار الحسابات.

### هـ. ربط أولياء الأمور بالأبناء (FamilyLink)
* نموذج **FamilyLink** يربط ولي الأمر (Parent) بطلبه (Student) عبر علاقة `ManyToMany` أو جدول وسيط، بحيث **يمكن ربط ولي الأمر بأكثر من طالب** (أبنائه) لمتابعة تقاريرهم وملخصاتهم اليومية والأسبوعية مجتمعة في لوحة واحدة.

### و. مرفقات الدروس والواجبات (Attachment)
* **Attachment:** رفع صور/ملفات لشرح الدروس أو الواجبات المنزلية (من المعلم) أو تسليمها (من الطالب)، مع حقول متابعة إدارية: `review_status` (بانتظار المتابعة/مقبول/مرفوض)، `review_notes`، و`reviewed_by`، إضافةً إلى نوع الملف وحجمه والرافع والشعبة.

### ز. تأكيدات القراءة والدعم (AnnouncementReadReceipt / FAQ / SupportRequest)
* **AnnouncementReadReceipt:** يسجل من قرأ إعلاناً أو واجباً (لكل مستخدم) ليمكّن المعلم/الإدارة من متابعة نسب القراءة.
* **FAQ:** أسئلة شائعة عامة متاحة للجميع.
* **SupportRequest:** طلبات الدعم الفني المرتبطة بالمستخدمين.

## 2. دورة العام الدراسي والأرشفة والترحيل (Academic Year Lifecycle)

النظام التعليمي ديناميكي، لذا يصمم الهيكل لدعم التغيرات دون فقدان الأرشيف:

### أ. الأرشفة (Archival)
* عند انتهاء العام الدراسي **لا تُحذف** بيانات الارتباط، بل تُوسم بالعام الدراسي وتُحفظ كسجل تاريخي.
* أي تغيير لاحق لا يمسّ بيانات السنوات السابقة (حفاظاً على الأرشيف والتقارير).

### ب. الترفيع السنوي (Annual Promotion / Roll-over)
* زر ترحيل واحد من لوحة مدير المدرسة: ينقل الطلاب تلقائياً إلى الصف التالي (و/أو الشعبة الجديدة) للعام الدراسي الجديد، مع بقاء سجلاتهم الأكاديمية السابقة.

### ج. انتقال الطلاب (Student Transfers)
* **بين الشعب داخل نفس المدرسة:** تغيير الشعبة المرتبطة بالطالب للعام الجديد مع الاحتفاظ بسجله.
* **إلى مدرسة أخرى:** تغيير المدرسة التابعة للطالب؛ تستطيع المدرسة الجديدة سحب السجل عبر **رمز التحويل (Transfer Code)** أو **الرقم الوطني**، مع بقاء الأرشيف في المدرسة السابقة.

### د. إعادة إسناد المعلمين (Teacher Re-assignment)
* جداول الإسناد مربوطة بالعام الدراسي، فيمكن للمدير تعديل توزيع المعلمين على الشعب والمواد كل عام دون المساس بسنوات سابقة.

## 3. الاستيراد والتصدير الجماعي والتكامل مع EduWave (Bulk Import / Export)

* **التوافق الهيكلي:** تصميم النماذج يطابق هيكلية EduWave (المديرية ➔ المدرسة ➔ الصف ➔ الشعبة ➔ الطالب) لسهولة الاستيعاب والاعتماد.
* **الاستيراد السريع (Bulk Import):** رفع كشوفات Excel/CSV من نظام EduWave في لوحة مدير المدرسة تحتوي (اسم الطالب، الرقم الوطني، الصف، الشعبة، واسم ولي الأمر/البريد)، فيقوم النظام بإنشاء الحسابات تلقائياً وربط الطلاب بشعبهم وأولياء أمورهم.
* **الاستيراد الجماعي للمعلمين:** رفع كشوفات المعلمين وتوزيعهم (المعلم، المادة، الصف، الشعبة) لإنشاء جداول الإسناد آلياً.
* **التصدير (Export):** تصدير الكشوفات والتقارير (Excel/CSV) للنسخ الاحتياطي أو التسليم للجهات الرسمية.
* **استراتيجية التكامل:** تكون منصة "آفاق" **الطبقة التفاعلية الذكية** (المتابعة، الذكاء الاصطناعي، والتقارير) فوق البيانات الأساسية القادمة من الأنظمة الرسمية، مع بقاء EduWave مصدر البيانات المعتمد.
