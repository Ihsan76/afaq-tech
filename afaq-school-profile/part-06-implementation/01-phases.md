# الجزء السادس: خطة ومراحل التنفيذ (Implementation Phases)

لضمان إنجاز المشروع بكفاءة عالية، تُقسم مراحل التطوير إلى الآتي:

* **المرحلة الأولى: الهيكل التنظيمي وقاعدة البيانات (SIS Core)**
  * إنشاء نماذج المدارس، السنوات الدراسية، الصفوف، الشعب، وإسناد المعلمين.
  * نماذج المستخدمين والأدوار مع أسماء المستخدمين الفريدة (RBAC) وربط ولي الأمر بأبنائه (FamilyLink).
  * دورة العام الدراسي: الأرشفة، الترفيع السنوي، انتقال الطلاب (رمز التحويل/الرقم الوطني).
  * تطوير أدوات الاستيراد والتصدير السريع (Bulk Import/Export via Excel/CSV) لكشوفات الطلاب والمعلمين المتوافقة مع EduWave.

* **المرحلة الثانية: نظام المتابعة الذكية وتكامل الواتساب**
  * بناء لوحات الواجبات والتنبيهات المتبوبة مع تأكيد القراءة (Acknowledgment).
  * تفعيل نظام التذاكر المنظمة بين ولي الأمر والمعلم.
  * ربط WhatsApp Cloud API لإرسال الإشعارات الطارئة والغياب.

* **المرحلة الثالثة: المساعد الذكي والتفاعل الصوتي**
  * دمج نظام RAG مع كتب ومناهج المنصة.
  * تفعيل الرد الآلي على الأسئلة المتكررة (FAQ Copilot) ونقاط الدعم الفني.
  * إعدادات المساعد الذكي لكل مستخدم (تعقيد اللغة، النبرة، الصوت، استرجاع السياق).
  * تجربة الصوت (STT/TTS) ولوحات التحكم والإحصائيات (Peak Hours & Charts).

* **المرحلة الرابعة: الاختبار، التدقيق، والإطلاق**
  * تشغيل اختبارات الجودة (`pytest` للفحص الخلفي و `tsc` للواجهة الأمامية).
  * الإطلاق التجريبي مع مدرسة نموذجية ثم التعميم.
